# `adm attach` Pi interface mapping

Pinned interface: `@earendil-works/pi-coding-agent@1.2.0` and `@earendil-works/pi-tui@1.2.0`.

`adm attach` keeps the workspace Durable harness as the only agent and transcript owner. Native `InteractiveMode` cannot attach to it because its constructor requires an `AgentSessionRuntime`, which owns an ordinary Pi session. The terminal reuses Pi's exported components and maps remote controls to the Durable workspace API. This is a mapped remote interface with listed gaps, not full native Pi parity.

| Pinned Pi control                                            | ADM mapping                                                                               | State                                                                                             |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Pi multiline editor, prompt history, abort                   | Pi TUI editor; HTTP prompt, abort, reconnect and detach                                   | Mapped                                                                                            |
| `app.tools.expand` (`Ctrl+O` by default)                     | Toggle `ToolExecutionComponent` call/result detail expansion                              | Mapped                                                                                            |
| `app.thinking.toggle` (`Ctrl+T` by default)                  | Hide/show rendered thinking blocks in this terminal                                       | Mapped; presentation-only                                                                         |
| `app.thinking.cycle` (`Shift+Tab` by default)                | Cycle supported levels and persist through workspace settings                             | Mapped; Durable model setting                                                                     |
| `/model` and model selector                                  | Exported Pi selector backed by workspace catalog and model API                            | Mapped                                                                                            |
| `/thinking` and thinking selector                            | `/settings` opens the exported Pi thinking selector; thinking level is persisted remotely | Partial; selector works, but `/thinking` alias is absent                                          |
| `/session` and `/resume`                                     | Select a Durable conversation branch within this workspace                                | Partial; selection works through `/resume`, but `/session` alias is absent                        |
| `/fork` and `/tree`                                          | Inspect paginated Durable history and fork at an entry                                    | Partial; fork works through `/tree`, but `/fork` alias is absent                                  |
| `/compact` and `/reset`                                      | Durable compaction task and selected-conversation reset                                   | Mapped                                                                                            |
| `/new`                                                       | No independent empty-conversation operation; `/reset` resets the selected conversation    | Gap; reset is not equivalent to a new Pi session                                                  |
| `/hotkeys`                                                   | No keybinding editor or help modal                                                        | Gap; terminal displays its supported controls in the footer                                       |
| `SettingsSelectorComponent` and `/settings`                  | ADM exposes thinking level and local thinking-block visibility                            | Partial; native theme/display, queue/follow-up, auto-compaction and retry settings are not mapped |
| Assistant, user, thinking, tool calls/results, errors, usage | Preserve structured Durable messages and render with Pi assistant/user/tool components    | Mapped                                                                                            |
| Footer and status                                            | Show current model, thinking level, usage, connection/activity and errors                 | Mapped                                                                                            |
| `/export`, `/import`, `/share`                               | No Durable transcript interchange or share-link contract                                  | Gap; native Pi session files do not represent Durable workspace history                           |
| `/login`, `/logout`                                          | Provider account authentication is outside the attached workspace terminal                | Gap; provider credential flow remains configurable and separate                                   |
| `/trust`, `/reload`, `/extensions`                           | No project trust prompt, extension reload, or terminal extension manager                  | Gap; attached client has no coding-agent runtime to own these actions                             |
| Clipboard/image paste and Pi session-file actions            | No remote binary upload or Pi session-file protocol                                       | Gap; HTTP terminal currently transports text and Durable records                                  |

The runner exposes `GET /branches`, `PUT /branch`, paginated `GET /tree`, `POST /tree` for a fork, `POST /compact`, `POST /reset`, and `GET/PUT /settings`. Branch index changes and active-conversation selection are committed together in the Durable harness. The terminal pins SSE streams to the selected conversation and clears/replays its cursor when the conversation changes. Bot public streams omit private assistant and tool diagnostics; only explicit bot messages are delivered as chat.

A Durable fork is a branch within one workspace, not a new Herdr space. Workspace identity and private files remain the isolation and deletion boundary. Reattaching restores the selected Durable conversation without starting a second agent owner.

`/retry` is an ADM-specific operation for retrying a safe failed provider turn. It does not implement Pi's `/resume` session picker.
