# Pi terminal parity audit

Pinned packages: Pi Coding Agent, Pi TUI, and Pi Durable 1.2.0.

`adm attach` now runs upstream `InteractiveMode` with a reproducible patch for remote services. Its runtime projects the existing workspace Pod's Durable conversation. It creates no ordinary Pi agent session, local transcript owner, or client-side coding executor. The dependency patch is applied during installation, image assembly, and release packaging and checked for idempotence and TypeScript compatibility.

| Interaction                           | Implemented behavior                                                                                                                                                                                                                                                                                           |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Startup, editor, footer and selectors | Upstream Pi layout, multiline editor, keyboard handlers, model and settings selectors, structured assistant/tool rendering, cwd/model/thinking/context and recorded usage.                                                                                                                                     |
| Model and behavior settings           | Workspace-owned model selection, thinking, steering/follow-up queues, automatic compaction, model cycling scope and cache-warming preference. Remote changes report acknowledgement failures. Presentation settings remain client preferences.                                                                 |
| Conversations                         | Durable branch/session selection, tree/fork/new/reset/compact, persisted display names, selected history replay and input deduplication. Native JSONL message branches import into Durable. Unsupported transcript context records fail visibly.                                                               |
| Shell commands                        | Coding `!`/`!!` execute in the owning workspace Harness. Output streams, spills when large, survives detach, and records a native Bash message. `!!` excludes output from model context. Execution intent is persisted before execution; restart reports interruption rather than repeating an unsafe command. |
| Detach and reconnect                  | Ctrl+C detaches without aborting the agent. Ctrl+R and `/reconnect` reconnect explicitly. `/abort` is a separate cancellation action.                                                                                                                                                                          |
| Resources and trust                   | Pod-owned prompts, skills, themes and context discovery; persisted project trust; explicit reload. Resource, trust, extension and tool-definition controls require the owning coding identity.                                                                                                                 |
| Extensions                            | Trusted tools and context/tool hooks run through the existing Durable registry. Commands and shortcuts use persisted operation receipts and typed dialog streams; concurrent/restarted retries preserve the original operation identity. Revoking trust cancels active commands.                               |
| Export and sharing                    | Native HTML and JSONL exports use the projected transcript, with private file permissions. `/share` exports locally, preserving ADM's publication policy. It does not automatically upload through Pi's Radius/gist sharing path.                                                                              |
| Authentication                        | Login/logout delegate to host `adm` and the cluster authority. Model metadata retains OAuth/subscription classification and account-permitted models. Provider credentials are never delivered to the terminal.                                                                                                |
| Bots                                  | Only user text and explicit bot messages enter native chat and exports. Private assistant/tool traces remain inspectable through authorized diagnostic APIs. Goal/loop/status controls remain available.                                                                                                       |

The extension bridge currently maps `context`, `tool_call`, and `tool_result` hooks. Other Pi lifecycle hooks, arbitrary custom widget/editor/header/footer component functions, and ordinary SessionManager mutation APIs are not implemented by this remote bridge and report explicit diagnostics. They require further remote contracts; this audit does not claim complete extension API parity. Provider-specific settings that have no Durable runtime mapping must not be described as applied to provider execution merely because a client preference was saved.

Native PTY checks exercise real startup, editor submission, model selection, live tool completion, failure and abort while attached, and clean detach. Bot PTYs verify live onboarding and explicit messages, one-copy reconnect replay, and content-free Working during private tool execution, including mid-run reconnect; successful, failed and aborted runs settle activity. HTTP/Durable checks cover workspace ownership, trust, extensions, queues, settings, unsafe-command recovery, persisted cache usage and transcript privacy. Release checks exercise packaged code outside the checkout. Live Herdr delivery, commercial-provider login, native macOS/arm64 execution and cross-node recovery remain separate acceptance checks. Fixture results do not establish those live outcomes.
