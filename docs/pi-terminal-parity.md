# Pi terminal parity audit

Pinned version: `@earendil-works/pi-coding-agent@1.2.0`, `@earendil-works/pi-tui@1.2.0`, and `@earendil-works/pi-durable@1.2.0`.

`adm attach` must keep the workspace Pod's Durable harness as the sole executor and transcript owner. The pinned `InteractiveMode` constructor takes `AgentSessionRuntime`, whose runtime owns local `AgentSession`, `AgentSessionServices`, and `SessionManager` objects; import/new/fork/switch create or switch ordinary Pi session files. `InteractiveMode` directly invokes these objects across prompt/steer/abort/compact, model runtime, branch navigation, resources/extensions, bash, trust/reload, and dozens of settings operations. Replacing only the runtime host would still reach host-owned filesystem/auth/trust paths. The current terminal maps Pi components onto workspace Durable APIs. This is not complete upstream parity; root has approved a reproducible local upstream patch introducing remote ports as the path to full parity.

Image requests use `POST /v1/workspaces/:id/input` with up to four PNG/JPEG/WebP images (4 MiB each, 6 MiB total JSON request). The Pod validates the payload and submits typed image content through the existing Durable harness, preserving conversation selection and request deduplication. Clipboard bytes remain in the client until submission; the host lifecycle bearer is never sent to the Pod.

The terminal CLI's `--admin-executable` plus `--admin-args-json` option provides the host CLI prefix without shell interpolation and permits argument values beginning with `--`. Provider auth does not use the workspace token or pass provider secrets through terminal arguments.

Durable import preserves supported message branches, Durable fork points, and the effective leaf; native compaction/context-edit/custom entry types fail visibly. The acceptance still requires the upstream remote-port patch, broader PTY coverage for every mapped selector/key binding, real Pod-owned trust/extension/reload contracts, and a disposable live Herdr run. Headless integration tests do not establish live Herdr acceptance.
