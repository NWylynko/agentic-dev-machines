# Pi terminal parity audit

Pinned version: `@earendil-works/pi-coding-agent@1.2.0`, `@earendil-works/pi-tui@1.2.0`, and `@earendil-works/pi-durable@1.2.0`.

`adm attach` must keep the workspace Pod's Durable harness as the sole executor and transcript owner. The pinned `InteractiveMode` constructor accepts a concrete `AgentSessionRuntime`; that runtime owns a local `AgentSession`, `AgentSessionServices`, and `SessionManager`, and its replacement operations create/switch ordinary Pi session files. Passing a fabricated client adapter would still create an unrelated owner or fail on controls. The terminal therefore maps Pi's TUI components and interactions onto workspace-scoped Durable APIs. This is not complete Pi parity yet.

| Pi behavior                                                | Current ADM behavior                                                                                                                        | Status / remaining work                                                                                                               |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Startup help, multiline editor, prompt history             | Pi TUI editor, Pi-branded startup/help, Enter submit, Shift+Enter newline, prompt history                                                   | Mapped; startup help can expand with Ctrl+O                                                                                           |
| Cwd/model/thinking/context/token/cost footer               | Workspace cwd and model, durable thinking level, aggregate assistant token/cost totals, context estimate and connection status              | Mapped; cache-hit breakdown and upstream footer customization are not exposed                                                         |
| Model selector                                             | Exported Pi model selector backed by workspace catalog/model API                                                                            | Mapped; model selection remains Durable-owned                                                                                         |
| Thinking selector and settings                             | Exported Pi selectors backed by workspace settings                                                                                          | Mapped for Durable thinking controls; settings with no workspace API are rejected, never reported as successful                       |
| Assistant/thinking/tool streaming                          | Pi assistant, user and tool components render structured Durable events; bot public view suppresses private assistant/tool content          | Mapped; diagnostics are opt-in                                                                                                        |
| Session navigation, tree, fork, new, compact, reset, retry | Durable conversation/branch and task APIs, selected conversation replay and cursor reconnect                                                | Mapped for workspace conversations; `/resume` retries a safe failed turn, it is not native JSONL session import                       |
| Ctrl+O, Ctrl+T, Shift+Tab                                  | Pi keybinding manager defaults map to tool details and thinking display/level controls                                                      | Mapped; Ctrl+C detach and Ctrl+R reconnect are ADM controls                                                                           |
| External editor                                            | Ctrl+G suspends the TUI, opens `$VISUAL`/`$EDITOR`, and returns edited prompt text                                                          | Mapped; editor executable is parsed as whitespace-separated argv                                                                      |
| Clipboard image paste                                      | Ctrl+V/Alt+V validates PNG/JPEG/WebP, then sends bounded image content with the next prompt to the workspace Durable input API              | Mapped; request identity is retained across ambiguous retries                                                                         |
| Provider login/logout                                      | `/login [PROVIDER]` and `/logout PROVIDER` suspend the TUI and invoke host `adm login/logout` with the configured nonsecret CLI argv prefix | Mapped; credentials and interactive auth stay on the host/lifecycle auth path                                                         |
| Import/share                                               | No native-session import or share-link operation exists in the current Durable workspace API                                                | Unimplemented; import needs a persistent Durable history bootstrap/import operation, and share needs an explicit publication contract |
| Trust/extensions/reload                                    | No workspace runtime API currently changes project trust or reloads extension/runtime state                                                 | Unimplemented; these operations must be Pod-owned and preserve Durable execution ownership                                            |
| Native bash mode and extension UI                          | No remote Pod shell-mode or extension UI contract                                                                                           | Unimplemented; no local shell or client-side extension execution is used                                                              |

Image requests use `POST /v1/workspaces/:id/input` with up to four PNG/JPEG/WebP images (4 MiB each, 6 MiB total JSON request). The Pod validates the payload and submits typed image content through the existing Durable harness, preserving conversation selection and request deduplication. Clipboard bytes remain in the client until submission; the host lifecycle bearer is never sent to the Pod.

The terminal CLI's `--admin-executable` plus `--admin-args-json` option provides the host CLI prefix without shell interpolation and permits argument values beginning with `--`. Provider auth does not use the workspace token or pass provider secrets through terminal arguments.

The acceptance still requires broader PTY coverage for every mapped selector/key binding and the missing Durable/runtime contracts above, plus a disposable live Herdr run. Headless integration tests do not establish live Herdr acceptance.
